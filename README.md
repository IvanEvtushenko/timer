# Учёт времени за ноутбуком

Простой набор на Python (стандартная библиотека, без установки зависимостей).

## Файлы
- `stopwatch.py` — секундомер с большими цифрами. Одна кнопка Старт/Пауза, поле
  «над чем работаешь», логирование каждого интервала. Стоп = закрытие окна.
- `font_preview.py` — окно-референс: образец времени в тонких шрифтах
  (Poppins / Open Sans / Zen Maru Gothic), чтобы выбрать шрифт цифр.
  Выбранное семейство вписывается в `CLOCK_FONT` в `stopwatch.py`, размер — в
  `CLOCK_SIZE`. Poppins и Zen Maru Gothic скачаны в `~/.local/share/fonts`.
- `report.py` — текстовый отчёт по логу (сегодня / неделя / по задачам / по дням).
- `app_tracker.py` — опциональный учёт экранного времени по приложениям
  (экспериментально, на GNOME/Wayland нужно расширение — см. шапку файла).

## Запуск
```bash
python3 stopwatch.py        # секундомер
python3 font_preview.py     # выбрать шрифт цифр
python3 report.py           # сводка
python3 report.py --days 30 # разбивка по дням за месяц
```
Горячая клавиша в секундомере: **Пробел** — старт/пауза. Закрытие окна = стоп
(текущий интервал дописывается в лог).

## Формат лога (`time_log.csv`)
Обычный текст (CSV), одна строка — один непрерывный интервал работы:

```
session_start,start,end,duration_sec,duration_hms,task
2026-06-18 10:00:00,2026-06-18 10:00:00,2026-06-18 10:25:00,1500,00:25:00,работа
2026-06-18 10:00:00,2026-06-18 10:30:00,2026-06-18 10:45:00,900,00:15:00,работа
```

- `session_start` — время первого старта сессии (без учёта пауз). Одинаково для
  всех интервалов между паузами в рамках одной сессии — по нему удобно
  группировать (например, суммировать время по сессиям);
- `start` / `end` — реальное время начала и конца конкретного интервала;
- `duration_sec` — длительность интервала в секундах (для подсчётов);
- `duration_hms` — то же для чтения глазами;
- `task` — что было написано в поле задачи.

Старый лог без `session_start` при первом запуске мигрируется автоматически
(каждая строка получает `session_start = start`), данные не теряются.

Почему CSV: остаётся читаемым текстом, но открывается в Excel/LibreOffice и
легко суммируется в Python/pandas для графиков и статистики.
